# Blinkit Grocery Sales Analysis

## Project Overview
* Interactive dashboard analyze the Blinkit grocery sales data featuring pivot table, slicer and pivot charts in Microsoft Excel.

## Tools & Technologies
* Application: Microsoft Excel
* Techniques used: Pivot tables,Slicer and Pivot charts.

## Key Business Insights
* Category ASnlaysing-- Analyze top selling product categories using dynamic Pivot charts.
* Store tier analyse-- Analyse sales distribution across different location tier.
* Filtering-- integrated slicers for instant data by outlet and product attributes.
